# WolfVRProject

// --- OVERVIEW --- //

   This project was made as a culmination of the different topics learned throughout the VR course. It includes different forms of locomotion, different types of weapons, and a fun gameplay loop. The game loop is a tower defense style of game. The player must last a certain amount of time to win and if the tower dies then the player loses. Below you will find descriptions of the different topics used in this project. 


// --- LOCOMOTION --- //

   This game includes two different forms of locomotion. Teleportation and regular movement. The teleportation is used by using grab in the left controller. There are different teleporation spots on top of the trees. It uses teleportation anchors in order to tell the VR inputs that it is an available spot to teleport to.


// --- WEAPONS --- //

   This game includes two different weapons. Projectile (crossbow like) and a melee weapon (sword like). Both weapons are attached to the right hand of the player. The projectile weapon takes a bit of time to reload and flashes green when done. It fires out a projectile that will kill enemies. The melee weapon is simple, it basically just does damage when it enters the enemy collider.


// --- USER INTERFACE --- //

   This game uses a user interface to convey the tower health and timer to the player, as well as the lose and win screens. The UI is attached to the main camera of the users headset so it is constantly visible to the player. It could have also been attached to the players hand as a sort of diagetic way to implement UI.


// --- CONTROLS --- //

-Left grab = teleport to teleport spots

-Right trigger = fire projectile weaopn

-B button = switch weapons
